# MusicNotationIcons

Music notation icons for Macro Deck 3, drawn from **Bravura**, the music font made by Steinberg for Dorico. Clefs, notes, rests, accidentals, dynamics, articulations and more, ready to put on your buttons, whether you control Dorico or another notation program.
